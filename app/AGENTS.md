# AGENTS.md

## Stack

* Next.js 15
* React 19
* TypeScript
* Node.js 22

## Commands

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Test

```bash
npm run test
```

## Conventions

1. Use TypeScript for all new code.
2. Components use PascalCase naming.
3. Utility functions use camelCase naming.
4. Keep React components in `src/components`.
5. Prefer functional components and hooks.

## Guardrails

1. Do not modify `package-lock.json` manually.
2. Do not remove TypeScript configuration.
3. Do not introduce new dependencies without justification.
